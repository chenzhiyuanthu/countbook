# 据实 · Countbook — 屏幕规格 / Screen-by-Screen UI Spec

> **据实 (Jùshí) — The Instrument of Record.**
> 这个应用从不说"你花太多了"。它只说「今日可用 −¥84.20」，然后让这个数字待在那里。
> *This app never says "you spent too much." It says 今日可用 −¥84.20 and lets that sit there.*

版本 v1.0 · 状态：实现基准 (implementation baseline) · 平台：Web (Vite + React 19 + TS, 手写 CSS) 与 iOS 17+ (SwiftUI, 零第三方依赖)

---

## 0. 如何阅读本文档 / How to read this

1. **每个屏幕**给出：一行目的 → ASCII 线框（手机宽；Web 宽屏若有实质差异则附第二张）→ 自上而下的逐元素表 → 空/载入/错误态 → 进出转场。
2. **线框约定**：只画上下边界与左边框，不画右边框——中文字符在等宽渲染里是双宽，右边框永远对不齐，画了反而是噪声。`▁▂▃` 表示柱形，`·` 表示 1px 发丝线上的刻度，`▮` 表示实心墨块，`( )` 表示可点热区，`[ ]` 表示按钮条。
3. **令牌名**（`--ink-900`、`--t-hero`）是唯一真值；所有十六进制与几何常量只存在于 `tokens/tokens.json`，由构建脚本生成 Web 的 `:root` 自定义属性与 Swift 的 `enum Palette` / `enum Metric`。**规格文档里出现的任何色值都是注释，不是来源。**
4. **文案键**（`today.hero.label`）来自第 14 节的文案册，是 i18n 唯一真值。线框与元素表里出现的中文必须能在文案册里按键找到。
5. **金额**在文档里一律写成最终渲染形态 `¥1,238.40`（¥ 0.44em ink-300 / 整数 ink-900 / 分 0.56em ink-300），负号一律 U+2212 `−`，从不用括号、从不用连字符。

## 1. 令牌速查 / Token quick reference

只列本文档引用到的。完整定义见 `tokens/tokens.json`。

### 1.1 颜色 / Colour

| 令牌 | Light | Dark (carbon) | 唯一用途 |
|---|---|---|---|
| `--paper` | `#F7F6F3` | `#121211` | 页面底 |
| `--surface` | `#FFFFFF` | `#1A1A18` | 卡片、表单、键盘 |
| `--surface-sunken` | `#F1EFEA` | `#0E0E0D` | 输入槽、已结月份底 |
| `--ink-900` | `#111110` | `#F2F0EA` | 主数字、主按钮底 |
| `--ink-700` | `#35342F` | `#C9C6BE` | 正文、类目名 |
| `--ink-500` | `#6E6C64` | `#8C897F` | 标签、备注 |
| `--ink-300` | `#A5A29A` | `#605D56` | 单位、分、时间戳、禁用态 |
| `--rule` | `#E2DFD8` | `#2B2A27` | 发丝线 |
| `--rule-strong` | `#C9C5BB` | `#3D3B36` | 分区线、聚焦卡边 |
| `--fig-over` | `#A32A22` | `#E0655A` | **仅两处**：为负的今日可用；偏差条中高于标准的一侧 |
| `--fig-held` | `#8A6A1F` | `#D2A64A` | **仅两处**：冷静期内的条目；待同步状态 |
| `--fig-spared` | `#2E5D4B` | `#6FA98A` | **仅两处**：已放弃总额；已终止订阅的已省 |
| `--fig-dead` | `#55565A` | `#7E8087` | **仅一处**：后悔金额（冷铅灰，全应用别处不出现） |

> **红色分工的裁决**：后悔金额**不用**红。红氧化色只留给"此刻可行动的负数"。后悔是**被扣留的墨色**——它永远赚不到一滴彩色。这既更克制，也让红色只表达一件事。
> **高对比令牌集**：`--rule` 在深色下对 `--surface` 不足 WCAG 3:1，`prefers-contrast: more` / `.accessibilityDifferentiateWithoutColor` 时切到 `--rule-hc`（light `#B8B4A9` / dark `#5A5852`），并给所有 `--fig-*` 数字追加 45° 斜纹或前缀符号。

### 1.2 字号 / Type scale

根 `1rem = 16px`；iOS 以 `.body` 为基准按同比例缩放（支持 Dynamic Type，比例保留、绝对值不写死）。

| 令牌 | px @1rem=16 | 字重 | 字距 | 用途 |
|---|---|---|---|---|
| `--t-hero` | 64 | 300 | −0.02em | 今日可用 |
| `--t-screen` | 44 | 300 | −0.02em | 记账金额、审判卡金额 |
| `--t-section` | 34 | 400 | −0.015em | 订阅年化、月度合计 |
| `--t-row` | 17 | 500 | 0 | 列表金额 |
| `--t-body` | 15 | 400 | 1.53 行高 | 正文 |
| `--t-label` | 11 | 600 | 中文 0.08em / 拉丁 0.14em 大写 | 标签行 |
| `--t-micro` | 10 | 500 | 0.06em | 脚注、ink-300 |
| `--t-mono` | 12 | 400 | 0 | 时间、ID、倒计时、更正行、指纹 |

全部数字：`font-variant-numeric: tabular-nums lining-nums`；SwiftUI `.monospacedDigit()`。

### 1.3 圆角（双值：视觉等价而非数值相等）/ Radii

| 角色 | Web | iOS (continuous) |
|---|---|---|
| `--r-rule` / 图表标记 / 账页行 | 0 | 0 |
| `--r-field` | 7 | 8 |
| `--r-card` | 9 | 10 |
| `--r-sheet` | 14 | 16 |
| `--r-pill` | 999 | 999（仅印章热区，本身不填充）|

### 1.4 间距与几何 / Spacing & geometry

`--sp` 基数 4。手机页边 `--gutter-screen: 20`；分区间距 `--sp-section: 32`；账页行竖向内边距 `--sp-row: 14`；金额右对齐栏宽 `--gutter-amount: 96`；Web 内容列 `--col-max: 720`。
图表常量（两端共享）：`--bar-w: 3`、`--bar-gap: 2`、`--bar-h: 6`、`--arc-stroke: 1`、`--unit-sq: 8`、`--unit-gap: 3`。
发丝线：Web `1px solid var(--rule)` + `@media (min-resolution:2dppx){ border-width:.5px }`；SwiftUI `Rectangle().fill(Palette.rule).frame(height: 1/displayScale)`。

### 1.5 动效 / Motion

唯一曲线 `--ease: cubic-bezier(0.32,0.08,0.24,1)`。

| 名称 | 时长 | 说明 |
|---|---|---|
| `figureSettle` | 220ms，右→左错开 18ms | 只有变化的数字位上移 6px 并交叉淡入 |
| `sheetPresent` | 280ms 进 / 200ms 出；遮罩 200ms linear 到 .28 | translateY 24→0 + opacity |
| `stampSlide` | 180ms | 2px 选中线在三段之间滑动 |
| `rowPrint` | 发丝线 240ms scaleX 0→1（左原点），内容 120ms 淡入，延迟 160ms | 保存后的"印刷"感 |
| `verdictSwipe` | 260ms | 卡片 ±120px + opacity |
| `coolArc` | 每分钟一次重绘，无缓动 | 唯一持续动画 |
| `holdRing` | 3000ms **线性**，无缓动 | 加缓动的计时器是在对时间撒谎 |
| `chartReveal` | 200ms，仅 opacity | 绝不从基线生长 |

`prefers-reduced-motion` / `.accessibilityReduceMotion` → 以上全部塌缩为 100ms opacity。

### 1.6 阴影 / Shadow

全系统**只有一个**，只用于记账面板与模态：
`0 1px 2px rgba(17,17,16,.04), 0 12px 32px -8px rgba(17,17,16,.16)`
遮罩 `rgba(17,17,16,.28)`，**不模糊**。

## 2. 全局构件 / Global chrome

### 2.1 导航模型

- **手机（Web ≤ 719px / iOS）**：底部 5 个文字标签（无图标），高 49pt + 安全区，顶边一条发丝线，选中项仅由字重 500→600 与 `--ink-500`→`--ink-900` 表示，**无填充、无指示条、无图标**。
  `今日 · 账页 · 报告 · 待购 · 设置`
- **Web ≥ 1080px**：左侧 200px 文字导航栏（同上顺序 + `订阅`），内容列仍为 720px 居中；导航项与内容列之间是一条 `--rule` 竖线。
- **Web 720–1079px**：无左栏，顶部一行文字导航，靠左，字距 `--t-label`。
- `订阅` 在手机上不占标签位：由 `报告` 页首行与 `设置` 页各有一个入口行。

### 2.2 `记` 按钮

56pt 圆形 `--ink-900` 实心，内含反白汉字 `记`（`--t-section`，字重 400），**不是加号**。位置：右下，距右 20、距底部标签栏 12。Web 同尺寸固定在内容列右下。长按 = 记账并保持面板开启（见 3.5）。

### 2.3 同步指示

从不出现转圈。任何时候同步状态只是一个词，`--t-micro`：`已同步` (`--ink-300`) / `待同步` (`--fig-held`) / `离线` (`--ink-300`)。它只出现在 `设置` 与 `设备与同步` 两处，**不在今日页**。

### 2.4 状态态的总原则 / States doctrine

| 类型 | 规则 |
|---|---|
| 载入 | 本地优先：账本来自 IndexedDB / SQLite，首屏预算 120ms。**禁止骨架屏、禁止转圈。** 若超 120ms 仍无数据，在内容位置显示一行 `--t-label` `--ink-300`：`正在读取账本…`。超 3s 转错误态。 |
| 空 | 空态不是插画，是一句陈述 + 一个动作。文案是事实，不是鼓励语（无"开始你的旅程"这类）。 |
| 错误 | 一条 `--fig-over` 发丝线 + 一行 `--t-body` `--ink-700` 事实描述 + 一个文字链接动作。**不用弹窗、不用 toast 报错**（toast 只用于可撤销的删除）。 |
| 样本不足 | 派生统计（后悔率、偏差条、小时散点）在样本不足时**不画图**，改印一行诚实计数：`还需 17 笔已判条目`。 |

### 2.5 金额渲染 / The `<Money>` contract

全应用**只有一个**金额渲染点：Web `<Money fen={123840} />`，SwiftUI `MoneyText(fen: 123840)`。

```html
<span class="fig" aria-label="一千二百三十八元四角"><i>¥</i>1,238<b>.40</b></span>
```
- `.fig i { font-size:.44em; color:var(--ink-300); margin-right:.08em }`
- `.fig b { font-size:.56em; color:var(--ink-300); display:inline-block; width:2.6ch; text-align:left }`
- SwiftUI：`HStack(alignment:.firstTextBaseline, spacing:0)` 三段 + `.accessibilityElement(children:.ignore).accessibilityLabel(full)`
- 属性：`size`（hero/screen/section/row）、`tone`（default/over/held/spared/dead）、`sign`（auto/always/never）
- Web 额外：`user-select` 落在外层 span 上并用 `::selection` 保证复制得到完整 `¥1238.40`（`<i>`/`<b>` 的内容参与复制，不额外插入空白）。
- **这是本设计系统里最容易静默损坏可读性的一处，因此它必须只被写一次。** 任何页面手写 `¥` 都是评审必须打回的错误。

### 2.6 派生量的权威定义 / Derived figures (single source)

```
daysRemaining      = daysInMonth − dayOfMonth + 1                 // 含今天
pool_fen           = standard_fen − spentBeforeToday_fen − fixedRemaining_fen
dailyAllowance_fen = floorDiv(pool_fen, daysRemaining)            // 余数推到最后一天
todayAvailable_fen = dailyAllowance_fen − spentToday_fen          // 今日可用（可为负）
dayStandard_fen    = floorDiv(standard_fen, daysInMonth)          // 月度日柱的标准线高度
coolingDays        = clamp(ceil(price_fen / 10000), 1, 14)        // ¥100→1 天，¥1400→14 天
leakEquivalent     = leakSum_fen / median90(entries > leakCeiling)
regretRate(cat)    = count(worthIt == false) / count(reviewedAt != nil)
```

> 今日可用**当天减法是全额的**：花掉 ¥68，数字就掉 ¥68（不是 ¥68÷18）。跨天时才重新摊平。这样"晚饭 ¥400"的后果和记账动作在同一拍到达。

### 3.5 状态

| 状态 | 呈现 | 文案 |
|---|---|---|
| 首次使用（无标准） | 主数字位置显示 `——`（两个 em dash，`--ink-300`），推导行替换为动作链接 | `today.empty.nostandard` 还没有设定月度标准 · 去设定 › |
| 有标准无条目 | 主数字正常显示满额；列表区一行 | `today.empty.noentry` 本月还没有记账 |
| 当日无条目（非首月） | 列表区一行 + T11 | `today.empty.today` 今天还没有记账 |
| 载入 | 主数字位 `——`；120ms 内通常不出现 | `common.loading` 正在读取账本… |
| 读取失败 | 主数字位 `——`，下方红发丝线 + 一行 + 文字链接 | `today.error.read` 账本读取失败。数据仍在本机。 / `common.retry` 重试 |
| 月末最后一天 | 推导行末尾追加 | `today.hero.lastday` 余 1 天 · 明日结账 |

### 3.6 转场

- **进入**：应用启动即在此屏，无转场；从其它标签切换为 100ms opacity 交叉淡入（**不做横向滑动**，标签之间没有空间关系）。
- **→ 记一笔**：`sheetPresent`（下沿升起 24px，280ms）。
- **→ 单笔详情**：iOS `NavigationStack` push（系统曲线替换为 `--ease`）；Web 为同列内替换 + 100ms opacity，浏览器返回可用。
- **← 从记一笔返回**：面板 200ms 下落，与之重叠地，账页区跑 `rowPrint`，同时 T2 跑 `figureSettle`。这是签名时刻，见第 4.7 节。
- **→ 周日审判**：全屏覆盖，从下 24px 升起 280ms，遮罩 .28。

### 13.5 合并模型（工程约定，影响 UI 文案）

- 每条写入是**只追加事件**，带混合逻辑时钟 (HLC)；同一 `txId` 冲突按最后写入者胜出。
- `更正` / `冲销` 本身就是事件，因此 `结账` 的不可变规则**跨设备自动成立**——账本与同步日志是同一数据结构的两层视图。
- UI 上因此不需要"解决冲突"界面，只需要 D-6.4 的一行提示与 `已保留两条记录`。

## 17. 实现清单 / Build checklist（对应本文档）

1. `tokens/tokens.json` → 生成 `web/src/styles/tokens.css` 与 `ios/Countbook/Design/Palette.swift`、`Metric.swift`。**十六进制与几何常量在仓库中只出现一次。**
2. `geometry/` 纯函数模块（TS 与 Swift 各一份实现）+ `geometry/fixtures/*.json` 共享测试向量：同输入必须产出同坐标数组。六种图表全部走它。
3. `<Money>` / `MoneyText`：唯一金额渲染点，带 `aria-label` / `accessibilityLabel`。
4. 记账中位耗时埋点（本地，不上传），显示在设置页——这是风险 #1 的仪表。
5. 结账定时任务（本地）：每月 1 日 00:00 封存上月；跨设备由 HLC 事件日志保证一致。
6. 样本门槛常量集中在一处：偏差条 14 天 / 后悔率 30 笔 / 小时散点 60 笔 / 标准提案 30 天 / 订阅识别 3 次（餐饮 5 次）。
